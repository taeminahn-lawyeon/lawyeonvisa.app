# 업무분야 페이지

한국어 `/ko/expertise`, 영어 `/expertise`에서 네 분야와 12개 세부 업무를 소개한다. 분야별 상세 주소는 `expertise-criminal`, `expertise-visa`, `expertise-residence`, `expertise-admin`이다. 세부 업무는 상세 페이지의 앵커로 연결한다.

## 분류 기준

| 분야 | 세부 업무 |
| --- | --- |
| 형사·사범심사 | 형사변호·판결 후 사범심사 / 입국규제 확인·해제 / 체류·취업 위반 / 출국조치·보호 |
| 비자·이민 | 취업·구직·전문인력 / 사업·창업·외국인투자 / 가족 초청·동반 입국 |
| 거주·국적 | 거주·영주·체류자격 유지 / 한국 국적·재외동포 / 외국인등록·체류기록 정리 |
| 행정 | 행정심판·행정소송 / 연금·투자금 반환 |

한국 국적의 취득·상실·회복과 외국인의 등록정보 정리를 구분한다. 가족의 최초 초청·입국은 비자 분야, 국내 정착 이후 가족관계 변화와 체류 유지 문제는 거주 분야에서 설명한다. 판결 후 사범심사는 형사사건을 원인으로 하는 심사에, 체류·취업 위반은 출입국관리상 위반에 초점을 둔다.

독립 업무로 반복되던 ‘기록 확인·법률의견’은 삭제하고 해당 사안의 검토 내용에 통합했다. 출국조치·보호 항목은 긴급 대응과 보호일시해제에 초점을 두고, 정식 행정심판·소송의 설명은 행정 분야에 모았다. 개별 사건에서 연계가 필요한 업무는 관련 분야 링크로 연결한다.

## 편집과 빌드

- 문안: `content/expertise*.ko.html`, `content/expertise*.en.html`. 목록과 상세 페이지의 제목·링크를 함께 수정한다.
- 등록부·메타데이터: `scripts/build-site.js`의 `PAGES` 배열.
- 페이지 전용 스타일: `css/expertise.css`. 공통 색상·글꼴은 `css/site.css`를 사용한다.
- 네비게이션: 공통 헤더의 업무분야 링크는 모바일 메뉴에도 복제된다. 네 메뉴가 겹치지 않도록 폭 1,024px 이하에서는 기존 모바일 메뉴로 전환한다.
- 배포 산출물은 `node scripts/build-site.js`로 생성한다. 생성된 루트·`ko` HTML은 직접 편집하지 않는다.
- 배포 전 `npm run validate`, `npm run validate:biz-i18n`, 새 페이지의 내부 링크·언어 전환·앵커를 확인한다.

소개 페이지는 정적 콘텐츠이며 접수 데이터베이스나 신청서 동작을 변경하지 않는다.
