# 아티클 문체 정비 중 확인한 정정 근거

2026-09-18. 공개 본문에 붙이는 출처 목록이 아닌 내부 변경 기록이다. 전체 법률 내용의 재검증을 뜻하지 않는다.

- 출입국관리법 제63조: 강제퇴거명령 후 보호는 최초 2개월, 위원회 승인에 따른 연장과 총기간 원칙 9개월·법정 예외 20개월. 제60조의 이의신청 기간은 일시해제 심사와 별도로 준수한다. https://www.law.go.kr/법령/출입국관리법/제63조
- 출국기한과 불복기한을 분리했다. 행정심판법 제27조·행정소송법 제20조의 기간과 집행정지 효력을 혼용하지 않는다. 단속 외국인 모두에게 입국금지 최소 5년이라는 단정은 확인 근거 부족으로 삭제했다.
- 국적법 제9조·제10조: 외국 국적 포기 기한은 국적회복허가일부터가 아니라 한국 국적 취득일부터 1년. 선서·국적회복증서 수여 시점과 고령자 등 외국국적불행사서약 예외를 보존했다. https://www.law.go.kr/법령/국적법/제10조
- 260901 체류민원 자격별 안내 매뉴얼 132–133쪽: D-9-5 학사학위 경로 OASIS 총 30점, 외자 도입 증빙. D-8의 명의 요건을 D-9 전체에 적용한 제3자 송금·송금앱 일률 배제는 삭제했다.
